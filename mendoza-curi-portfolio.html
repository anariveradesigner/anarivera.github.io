Overview

Transforming manual real estate workflows into a centralized digital experience

This project focused on improving how a growing real estate agency managed its day-to-day operations. Instead of relying on fragmented processes, the goal was to design a solution that centralized property management while making information easier to update and maintain.

The outcome was a custom CRM connected to a responsive marketing website, enabling the agency to manage listings, documents, images, and client information from a single platform. The solution evolved through close collaboration with the client, ensuring every feature addressed real business needs and supported a more efficient workflow.

Problem

Managing properties shouldn't require multiple tools

The agency managed its daily operations through fragmented processes, making it difficult to keep property information organized and up to date. Publishing listings, updating details, and handling documents required repetitive manual work, increasing the risk of inconsistencies and slowing down the team's workflow.

The challenge wasn't simply to build a website: it was to create a centralized system that reflected the agency's real workflow while remaining intuitive enough for non-technical users to use confidently every day.

Approach

Inclusive Design & Double Diamond

This project followed an Inclusive Design approach, using human diversity as the starting point for designing more accessible onboarding experiences.

Instead of assuming that all users should interact with the same interface in the same way, the project explored how onboarding could adapt to different levels of digital literacy while maintaining a shared, accessible experience.

How it works

A centralized system built around the agents' daily workflow

Every property, document, and client interaction lives in one place. Agents manage the full lifecycle of a listing — from upload to publication — while sensitive data stays protected in a private workspace.

01
Centralized property management
Agents upload images, technical details, and descriptions for each listing, using predefined lists to quickly add amenities and nearby points of interest. Every property is assigned a unique ID code for easy identification.
02
Private agent workspace
A separate, access-restricted area stores owner contact information, ownership documents, commission percentage, and internal notes, keeping sensitive data visible only to agents.
03
Real-time website & spreadsheet sync
Any update made in the CRM is instantly reflected on the public website and in an auto-generated Excel file for extra control. Deleting a property removes it from the online catalog while keeping its full record in the system.
04
Automated Drive folders
A Google Drive folder with the property's photos is created automatically for every new listing, keeping media organized without manual effort.
05
Document generator
Contracts can be created instantly from predefined text templates, saving agents time and reducing repetitive administrative tasks.

Learnings

Design takeaways

Designing for inclusion means adapting experiences to people rather than expecting people to adapt to technology:

  • Inclusive Design starts with understanding diverse user needs, not designing for an "average" user.
  • Personalization can reduce cognitive load and improve first-time user experiences.
  • AI can enhance accessibility when used as a supportive tool, not as the product itself.
  • Early and repeated user testing led to more informed design decisions.
  • Iteration is an essential part of building meaningful user experiences.
What's next

Beyond the prototype

My next goal is to work on its launch as a fully functional prototype powered by real AI models capable of dynamically adapting onboarding based on user behavior.

Additional opportunities include validating the framework with larger and more diverse user groups, integrating behavioral analytics, measuring long-term retention, and exploring adaptive onboarding in domains beyond EdTech, such as healthcare, finance, and government digital services.
